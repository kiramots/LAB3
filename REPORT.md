## 2. Відповідь на контрольне запитання

**Запитання:** `Як видалити дублікати зі списку за допомогою множини?`

**Відповідь:**

`В Python для видалення дублікатів зі списку можна використати (set), оскільки вона зберігає лише унікальні елементи, видаляючи всі повторення. Наприклад:`
numbers = [1, 1, 3, 4, 5, 2, 3]
test = list(set(numbers))
print(test)
`Результатом буде: 1, 3, 4, 5, 2`
